# AI & Data Careers Intelligence Platform

An AI-themed analytics dashboard that visualizes global AI and Data career trends using cleaned job market data.

## Project Overview

This project analyzes AI and Data job market trends across job listings, salaries, remote work, hiring countries, job roles, and experience levels.

## Dashboard Versions

### Tableau BI Dashboard
The Tableau version focuses on business intelligence analysis, KPI tracking, and visual storytelling using cleaned AI job market data.

### AI-Themed Web Dashboard
The web version is built using HTML, CSS, JavaScript, and Chart.js to present the same insights in a modern AI-style interface.

## Key Metrics

- Total Job Listings: 50,000
- Average Salary: $110.8K
- Remote Jobs: 32.96%
- Top Hiring Country: UK
- Top Job Role: MLOps Engineer
